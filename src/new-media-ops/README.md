# New Media Ops

New Media Ops is a draft-first content operations plugin for Chinese new-media workflows.

The plugin combines an agent skill with a local CLI:

- The skill guides article analysis, topic selection, writing, review, and platform adaptation.
- The CLI provides deterministic content packages, Markdown formatting, preflight checks, and WeChat draft API staging.

MVP targets:

- WeChat Official Account article drafts (`article_type: "news"`)
- WeChat image-text / Xiaolushu drafts (`article_type: "newspic"`)
- Xiaohongshu draft packages for browser-assisted or manual posting

The plugin never performs final public publishing in this MVP.

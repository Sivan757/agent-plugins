# Model Index

Use this as the internal model catalog for `consulting-advisor`. Select one primary model by matching the user's intended output, then ask model-shaped questions. If no entry fits well, browse for authoritative current guidance and report confidence.

## Selection Heuristic

1. Identify the artifact or decision: resume, presentation, strategy, campaign, product choice, technical decision, learning plan, negotiation, etc.
2. Choose the model that structures the user's missing information, not the model that sounds most famous.
3. Combine only when necessary: use a diagnostic model to frame the problem, then a domain model to solve it.
4. For ambiguous consulting tasks, default to Issue Tree/MECE for decomposition plus the closest domain model.

## Confidence Rubric

- High: canonical and stable in the field, such as STAR for behavioral interviews, SMART for goals, 4P/STP for marketing, SCQA/Pyramid Principle for structured communication.
- Medium: widely used but context-sensitive, such as RICE vs. MoSCoW for prioritization, OKR vs. KPI for management.
- Low: niche, new, localized, or unsupported by strong sources; browse before relying on it.

## General Problem Solving

| Task | Primary models | Use when | First questions |
| --- | --- | --- | --- |
| Diagnose a vague problem | First Principles, Issue Tree, MECE, 5 Whys | The user describes symptoms but not root cause | What is the observable symptom, what changed, and what constraints cannot change? |
| Root cause analysis | 5 Whys, Fishbone/Ishikawa, Fault Tree | Failures, incidents, quality problems | What happened, when did it start, what evidence separates cause from coincidence? |
| Make a decision | Decision Matrix, Expected Value, Reversibility, OODA | Several options with tradeoffs | What options exist, what criteria matter, and which downside is unacceptable? |
| Manage risk | Premortem, Probability-Impact Matrix, Scenario Planning | Plans with uncertainty | What would make this fail, how likely is each risk, and what early signal reveals it? |
| Set goals | SMART, OKR, North Star Metric | Targets, plans, accountability | What measurable outcome matters, by when, and what leading indicators prove progress? |

## High-Stakes Domains

Use structured models for clarity, not as a substitute for licensed professionals.

| Domain | Framing models | Boundary |
| --- | --- | --- |
| Medical | Differential diagnosis framing, risk triage, shared decision-making | Do not diagnose; recommend clinician or emergency care when appropriate |
| Legal | IRAC, issue spotting, risk matrix | Do not provide legal conclusions; recommend qualified counsel |
| Tax/accounting | Decision tree, compliance checklist, scenario analysis | Do not provide definitive filing advice |
| Investing | IPS, asset allocation, risk tolerance, expected value | Do not provide personalized financial advice without caveats |
